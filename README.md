# Onboarding Sandbox 1

데브칸반 온보딩 체험용 **테스트 레포**입니다.

가입하면 별도 설정 없이 이 레포에서 바로 작업 카드를 만들어 보고,
결과가 오픈소스 커밋으로 남습니다. 여러분의 기여는 커밋의 `Co-authored-by`로 기록됩니다.

## 이렇게 체험합니다

1. 데브칸반에서 **Sisyphus Team** 온보딩 공간에 진입
2. GitHub · LLM 키 연동
3. "이 부분 바꿔보고 싶다" → 작업 카드 생성·실행
4. 완료되면 `dev`에 반영되고, 릴리스 시 `main`에 병합되어 기여로 등재

## 무엇을 바꿔볼까요?

가장 간단하게는 [`index.html`](index.html)의 문구/색을 바꿔보세요.
"환영 메시지를 바꿔줘", "배경색을 다르게 해줘" 같은 카드로 시작하면 됩니다.
